About the cat game archive

This experiment puts two historical builds back in the browser. The first is a movement and jumping prototype; the latest is a complete, illustrated platformer called Miso’s Moonlight Run.

Two source snapshots

  • May 2025 · Gemini: movement, jumping and eight selectable cats. Commit fb041d6 · Play original.
  • July 2026 · GPT 5.6 Sol: three illustrated districts, wall jumps, pouncing, checkpoints, collectibles and animated artwork. Commit 0663c3c · Play original.

What the comparison can tell you

The project author identifies the initial version as Gemini-assisted and the latest as built with ChatGPT using GPT 5.6 Sol in July 2026. The labels show when the work was done, not when it was pushed. The first commit is dated May 19, 2025; the latest snapshot is dated July 21, 2026. The exact Gemini version was not recorded.

This is an example of iterative development with AI, not a controlled measurement of model capability. The brief, gameplay and amount of iteration changed. Compare the interactions and implementation choices rather than treating one build as proof that one model is universally better.

What is preserved

Each archive directory contains the original HTML, CSS, JavaScript and images from its source commit. Original game behaviour and limitations are retained, including the May movement sandbox. Only assets needed to run the July game are included; production experiments and test artifacts remain in the source repository.

The embedded viewer uses a separate preview entry point and bridge script to add responsive scaling, accessible selector labels, touch input and keyboard focus handling to the May build. July uses its own responsive interface and controls. Game logic is unchanged. Switching builds or restarting reloads the game; July’s saved progress and settings remain in this browser. Runtime assets load only after choosing Play.

May: use Left/Right to move and Space to jump. Escape moves focus to Stop & reset. July: A/D or arrows to move, Space/W/Up to jump, Shift/X to pounce, Escape/P to pause, and Shift+Escape to return focus to the viewer. July includes its own touch controls; landscape gives more room.
