About the cat game archive

This experiment puts two historical builds back in the browser. The original project began as a movement and jumping prototype, then changed direction into a snake-style game.

Two source snapshots

  • May 19, 2025: movement, jumping and eight selectable cats. Commit fb041d6 · Play original.
  • June 29, 2025: fish collection, scoring and a following cat trail. Commit 023b217 · Play original.

What the comparison can tell you

The project author identifies the initial version as Gemini-assisted and the later iteration as ChatGPT-assisted. Dates are the Git commit dates, not model release dates. Exact model versions, prompts and generation time were not recorded with these snapshots.

This is an example of iterative development with AI, not a controlled measurement of model capability. The brief, gameplay and amount of iteration changed. Compare the interactions and implementation choices rather than treating one build as proof that one model is universally better.

What is preserved

Each archive directory contains the original HTML, CSS, JavaScript and images from its source commit. Original game behaviour and limitations are retained, including the May movement sandbox and the June build’s lack of a collision-based game-over state.

The embedded viewer uses a separate preview entry point and bridge script to add responsive scaling, accessible selector labels, touch input and keyboard focus handling. It does not rewrite the game logic. Switching builds and stopping or restarting a game resets that session.

Keyboard: click Play, then use the arrow keys; Space jumps in the May build. Escape moves focus to the viewer’s Stop & reset button. The on-screen controls support touch and keyboard activation.
